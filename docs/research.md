# 项目调研

## 当前主线

这个项目当前只保留一条主生成路线：

- `Stable-Hair`

原因：

- 比 `GAN` 路线更接近我们要的真实感
- 更适合继续往身份保持和多视角一致性扩展
- 与“中国审美参考库 + 个性化推荐”更匹配

## 当前保留的研究方向

### Stable-Hair

- 仓库：https://github.com/Xiaojiu-z/Stable-Hair
- 角色：当前项目的主生成后端
- 用途：正面高真实感发型迁移
- 现状：代码已接入，当前机器受限于显存

### StableHairV2

- 仓库：https://github.com/sunkymepro/StableHairV2
- 论文：https://arxiv.org/abs/2507.07591
- 角色：多视角一致生成的后续路线
- 用途：后续正面 / 左侧 / 右侧一致性与 3D 扩展

### DECA

- 仓库：https://github.com/yfeng95/DECA
- 角色：可选 3D 头脸分析模块
- 用途：头骨、姿态、几何比例辅助分析

## 参考数据方向

### 中国审美参考图主库

- 来源：人工筛选的真人彩色头像参考图
- 要求：
  - 清晰
  - 光线自然
  - 正面或轻微侧正面
  - 发型结构完整
  - 不夸张修图

### 韩国发型资料

- 只作为补充参考
- 用于扩展相邻风格，而不是替代中国审美主库

## 当前结论

1. 继续优化推荐层是必要的
2. 真实感的关键仍在生成层和参考图质量
3. 当前机器不适合作为 `Stable-Hair` 最终运行机
4. 下一步应该把项目迁移到更大显存机器继续跑
